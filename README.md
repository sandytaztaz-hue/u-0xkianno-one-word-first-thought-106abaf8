Entry for the make.fun bounty [One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8).

The brief asks for exactly one word: the first word that comes to mind, no topic, no explanation, no second draft. A judge model compares entries two at a time and crowns the most interesting word. Surprise, vividness and a spark of wit beat safe filler.

## The word

**syzygy**

Three celestial bodies lined up in a row — sun, moon, earth at an eclipse — in six letters with three y's and no ordinary vowel. It looks strange on first read, sounds like a hiss, and calls up a clear cosmic image at once. It is the word that lands hardest, and it is not one of the words the field keeps repeating.

## How it was chosen
The field's visible entries repeat the same beautiful rare words — petrichor, defenestration, apricity — so a copy shares one rate with every other copy and only the earliest receipt places above them. Syzygy was nowhere among the visible entries: surprising, vivid, specific, and its own.

## Run

```sh
node main.ts
```

The program writes `syzygy` (no trailing newline, 6 bytes) to `entry.txt` in the output directory, resolved in this order: the `MAKEFUN_OUTPUT_DIR` environment variable, the `--output` flag, then `/output`.
